Development Notes

Grenade Battles is being built around fast, simple, and satisfying PvP gameplay. The main focus is making each throw feel responsive and rewarding.


Current testing is focused on grenade behavior, arena pacing, player feedback, and making sure matches feel competitive without becoming too complicated.


After the main combat systems feel solid, the team will move into cosmetics, progression, effects, and polish.

Developer Message

Grenade Battles is designed to be fast, chaotic, and easy to jump into. The goal is to create a game that feels fun instantly while still having room for skill.
